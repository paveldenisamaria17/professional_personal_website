MindMap

View repo →

A brainstorming platform where a user types in a few ideas and gets back a graph of related new ideas, rendered like a constellation growing out of the original words. The goal is to let people see their thinking expanded visually and explore it from different angles — whether they just want to keep track of ideas, compare them against each other, or push a train of thought as far as it can go.

  • A set of tools to work with the generated graph: comparing ideas, generating new ones, and re-styling the layout until it fits.
  • Each word shows its meaning and why it's linked to its neighbors, so the graph stays explainable, not just decorative.
  • Graphs are saved and organized by creation date, so past sessions can be revisited and analyzed later.
  • Runs on two servers: a Node.js server handles authentication and the database, while a Python server generates related words and links using the WordNet lexical database and Wu–Palmer similarity scoring.
  • Frontend built with plain HTML and CSS.
